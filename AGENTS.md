## Before changing anything

1. Explain first the concrete effect for the product or operations.

## Sources of truth

1. The code, Git and the checks actually run describe the real state.
2. `docs/ARCHITECTURE.md` holds durable decisions and their reasons.
3. `BACKLOG.md` tracks what is done and what remains.
4. The guides in `docs/guides/` describe operations and checks that can
   be replayed.

## During the work

- Do not commit without an explicit request from the project owner.

## Before declaring it done
