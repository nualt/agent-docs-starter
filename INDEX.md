# Document index

One line per document: what it contains, and when to read it.

## Entry documents

- `README.md`: what the project is and how to use it. Written for the client.
- `AGENTS.md`: how to work in this repository. Loaded in every session.

## Reference documents

- `docs/ARCHITECTURE.md`: how the system is built and why, decisions
  included. Read before touching the structure.
- `docs/DESIGN-SYSTEM.md`: visual rules. Read before any interface
  change. Update after a decision is approved, never before.

## Project tracking

- `BACKLOG.md`: what is done and what remains.

## Guides

- `docs/guides/deployment.md`: release procedure. Reread before every
  deployment.
- `docs/guides/smoke-tests.md`: checks to replay before a deployment or
  a merge.
